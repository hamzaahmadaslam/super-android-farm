# System packages a headless Android 13 farm never uses. They are disabled per user
# (`pm disable-user --user 0`), not removed: the setting lives in the Android's own /data,
# survives restarts and is undone with `pm enable`.
#
# Measured with this exact list on Android 13: about 170 MB less memory per Android
# (1,079 -> 908 MB), 83 -> 75 processes, and the Bluetooth crash loop at every boot is gone.
# Camera, microphone, network, app installs and logins were verified afterwards.
#
# One package per line; `#` starts a comment. Add your own with performance.trim_extra,
# protect one with performance.trim_keep.
